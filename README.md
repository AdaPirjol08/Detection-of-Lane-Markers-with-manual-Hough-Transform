      Detection of lane markers

      
• Objective: Implement an application in Python to detect lane marker with manual coded Hough Transform, not predefined from cv2 library

• Brief description: In driver asistace applications, detecting lanes is an imprtant task. If the lane detection is a good
one it can help the driver by worning him in the moment that he oversteps the lane or if the rode turs right or left
and if the turns are week or strong ones. In order to detect lane in images Houhg transform is used. The process of
using the Hough transform (HT) to detect lines in an image involves the computation of the HT for the entire
image, accumulating votes in an accumulator array and searching the array for peaks which hold information of
potential lines present in the input image
